Verdade ou Desafio – EE

O Verdade ou Desafio – EE é um jogo web open-source do Desenvolvedor EE, baseado no clássico jogo de Verdade ou Desafio.

Atualmente, o projeto está passando por um processo de reformulação, conserto e melhoria, visando maior estabilidade, melhor experiência do usuário e uma base mais organizada.

Código-fonte disponível em: GitHub – Verdade ou Desafio – EE
