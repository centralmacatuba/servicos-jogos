# Verdade ou Desafio – EE

O **Verdade ou Desafio – EE** é um jogo web open-source desenvolvido pela **Central Macatuba**, focado em entretenimento digital simples, acessível e comunitário.

## 🎮 O que é

Um jogo clássico de **Verdade ou Desafio**, adaptado para o ambiente digital, permitindo que grupos de amigos joguem diretamente pelo navegador, sem necessidade de cadastro ou instalação.

## 🔧 Estado atual do projeto

⚠️ **O projeto está em processo de reformulação, conserto e melhoria.**

Isso inclui:
- Correções de bugs existentes
- Melhorias na experiência do usuário
- Reestruturação do código
- Padronização visual e técnica
- Preparação para futuras funcionalidades

## 🚀 O que será

- Interface mais moderna e responsiva
- Melhor organização das perguntas e desafios
- Sistema mais estável e escalável
- Base pronta para futuras expansões
