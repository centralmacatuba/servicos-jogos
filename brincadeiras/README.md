# Brincadeiras – EE

O **Brincadeiras – EE** é um projeto open-source da **Central Macatuba**
que reúne diferentes brincadeiras e jogos simples em formato web.

## 🎮 O que é

Uma plataforma de brincadeiras digitais para navegador,
com foco em diversão casual, simplicidade e acessibilidade.

## 🚧 Estado atual do projeto

🛠️ **Em desenvolvimento.**

Novas ideias e brincadeiras podem ser adicionadas ao longo do tempo.

## 🚀 O que será

- Coleção variada de brincadeiras
- Interface simples e intuitiva
- Estrutura modular para fácil expansão
- Ideal para uso educacional ou recreativo
