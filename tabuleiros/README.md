# Tabuleiros – EE

O **Tabuleiros – EE** é um projeto open-source da **Central Macatuba**
voltado para a criação de jogos de tabuleiro em formato digital.

## 🎮 O que é

Uma base para jogos de tabuleiro jogáveis pelo navegador,
com foco em simplicidade, reutilização de código e acessibilidade.

## 🚧 Estado atual do projeto

🛠️ **Em desenvolvimento.**

A estrutura ainda está sendo definida.

## 🚀 O que será

- Jogos de tabuleiro digitais simples
- Interface genérica reutilizável
- Base para múltiplos tipos de jogos
- Código organizado e extensível
