# Uno – EE

O **Uno – EE** é um jogo web open-source inspirado no clássico jogo de cartas UNO,
desenvolvido pela **Central Macatuba**.

## 🎮 O que é

Uma adaptação digital do jogo UNO para navegador, focada em partidas simples,
acessíveis e sem necessidade de instalação.

## 🚧 Estado atual do projeto

🛠️ **Em desenvolvimento.**

O projeto ainda está em fase inicial e pode sofrer mudanças estruturais.

## 🚀 O que será

- Implementação completa das regras do UNO
- Interface amigável e responsiva
- Estrutura preparada para modos futuros (local ou online)
- Código modular e fácil de manter
